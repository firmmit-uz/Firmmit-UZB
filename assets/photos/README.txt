FIRMMIT UZBEKISTAN — PHOTOS
============================

Drop your photos in THIS folder using the exact filenames below.
The website detects each file automatically — if a file is present it
replaces the blue gradient placeholder; if it's missing, the gradient
stays. No code changes needed.

Recommended: photos taken in March (best match for the Uzbekistan branch).
Use .jpg (or rename .png to .jpg). Landscape orientation, ~1600px wide.

LOGO (site-wide) — light + dark versions
----------------------------------------
  ../logo.png        <-- DARK logo (transparent PNG), for white backgrounds
                         (the header after you scroll down)
  ../logo-light.png  <-- WHITE / light logo (transparent PNG), for dark
                         backgrounds (the hero header and the footer)
  Put both one folder up, in assets/. The site auto-detects them and swaps
  the built-in mark on every page — dark logo on white, light logo on dark.
  (If you only have one, name it logo.png and it's used on both.)

HOW TO GET THEM FROM GOOGLE PHOTOS
----------------------------------
  Option A: open each photo → Download (or Shift-select many → Download),
            then copy the files here and rename per the list above.
  Option B: in Google Photos create an album → Share → Create link,
            and send me that public link — I'll pull the images.
